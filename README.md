# Partner Ecosystem Intelligence

AI-powered partner ecosystem analysis and decision-support application.

## Overview
Short explanation of the business problem and what the application does.

## Features
- Partner portfolio dashboard
- Partner scoring and prioritisation
- Pipeline and revenue analysis
- Partnership lifecycle tracking
- Partner profiles
- AI Partner Advisor
- Local LLM using Ollama + Llama 3.2
- RAG-based partner document retrieval

## Architecture

Partner Data (CSV)
        ↓
Analytics & Scoring
        ↓
AI Partner Advisor
        ↑
Partner Documents
        ↓
Retrieval / RAG
        ↓
Llama 3.2 via Ollama

## Tech Stack
Python | Streamlit | Pandas | Altair | Ollama | Llama 3.2
